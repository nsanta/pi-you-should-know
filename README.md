# pi-you-should-know

A [pi](https://github.com/earendil-works/pi-coding-agent) extension implementing the
"You should know" background-reviewer pattern: a quiet second agent reviews the
conversation every N steps and surfaces hidden decisions, silent assumptions, and
architectural blind spots as non-blocking notes above the prompt.

Status: work in progress. Full documentation lands with the first release (task T6).
Design and task breakdown: [odd/tasks/you-should-know.md](odd/tasks/you-should-know.md).
